# Dynamic Island Concept

## About

This project is a front-end concept inspired by the Dynamic Island interface. It was created for educational and portfolio purposes to demonstrate UI animation, CSS transitions, SVG graphics, and JavaScript interactions.

This project is **not affiliated with Apple Inc.** and does not claim ownership of any Apple trademarks, patents, or proprietary technologies. It is an original implementation created as a design and development exercise.

---

## Features

*  **Music Interface**

  * Animated album artwork
  * Progress bar
  * Audio visualizer
  * Playback controls

*  **Face ID Concept**

  * Custom SVG face icon
  * Dual rotating scan rings
  * Success checkmark animation
  * Dynamic Island closing animation

* **Call Interface**

  * Incoming call UI concept
  * Contact avatar animation

---

## Usage

Open `index.html` in your browser or run the project using a local development server.

Click any of the buttons below the Dynamic Island to preview the available animations and interactions.

* **Music**
* **Face ID**
* **USE CALL**
